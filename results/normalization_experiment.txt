EXPERIMENT CONTEXT & HYPOTHESIS:
  In the baseline feature pipeline, 132 of the 247 spatial features are raw
  screen coordinates (landmark_i_x, y, z). The diagnostic revealed the Random
  Forest relied 75.8% of its total feature importance on absolute screen positions,
  and unnormalized temporal features were distorted by subject-to-camera distance.
  Hypothesis: Normalizing coordinates to the hip midpoint and scaling by torso length
  will make the model invariant to camera distance and position, dramatically
  reducing confusion between Standing and Walking.

DATASETS & EXPERIMENTAL CONDITIONS:
  - All three representations evaluated on identical train/test splits (792 rows)
  - Train: 495 rows (5 sequences: S1 trials)
  - Test: 297 rows (3 holdout sequences: C1_S1_A6_T2, C1_S2_A7_T1, C1_S2_A8_T1)
  - Classes: standing (99 test), sitting (99 test), walking (99 test)

4. IN-DEPTH ANALYSIS & ANSWERS TO CORE RESEARCH QUESTIONS
──────────────────────────────────────────────────────────────────────────────

Q1: Did normalization improve Standing recognition?
  - Random Forest Standing F1: A=0.9245 -> B=0.9245 -> C=0.9741
    Improvement: +4.96% points over baseline temporal model.
  - Standing precision reached 100.0% in RF Normalized (no false standing predictions!).

Q2: Did normalization improve Walking recognition?
  - Random Forest Walking F1: A=0.9130 -> B=0.9130 -> C=0.9754
    Improvement: +6.23% points over baseline temporal model.
  - Walking recall jumped from 84.85% (B) to 100.0% (C)! Every single walking frame was correctly recognized.

Q3: Did Standing <-> Walking confusion improve?
  - In Baseline B (Random Forest): 15 walking frames were misclassified as standing.
  - In Normalized C (Random Forest): EXACTLY 0 walking frames were misclassified as standing!
  - Standing-Walking confusion on walking frames was completely resolved (0 errors).
  - The key target metric (Standing F1 + Walking F1):
    * Baseline Spatial A (RF): 1.8376
    * Baseline Temporal B (RF): 1.8376
    * Normalized Temporal C (RF): 1.9495 (+0.1120 improvement!)

Q4: Which feature changes appear responsible?
  1. Removal of raw screen coordinates (landmark_i_x, y, z): The model can no longer
     use screen position (y-level) as an artificial shortcut for activity.
  2. Hip-centering & torso-scaling of landmarks: Body geometry is now purely posture-based.
  3. Scale-invariant temporal displacement: Motion speed is calculated in units of
     'torso lengths per second' rather than screen pixels, eliminating distance distortion.
  4. Explicit hip angles (shoulder->hip->knee): Gives clean biomechanical distinction
     between standing (hip angle ~180 deg) and sitting (hip angle ~90 deg).

Q5: What about Logistic Regression?
  - LR Standing+Walking F1: A=1.8786, B=1.8887, C=1.8309
  - LR suffered a slight drop on sitting (F1=88.7% vs 100%) without absolute Y coordinates,
    showing that linear hyperplanes struggle with non-linear postural manifold without position,
    whereas tree-based Random Forest thrives on the normalized biomechanical features (98.32% accuracy).

Q6: Which representation should be used going forward?
  Representation C (Normalized Spatial + Temporal Features) paired with Random Forest is
  the superior architecture. It achieves the highest accuracy (98.32%), highest standing F1 (97.41%),
  highest walking F1 (97.54%), 100% walking recall, and eliminates distance-dependent overfitting.

Q7: Remaining limitations:
  1. Test set evaluated 3 activities (no running in this subset).
  2. Dataset consists of 2 subjects (pipeline validation); multi-subject diverse validation remains necessary.
  3. For live webcam prediction, the real-time feature extractor must implement this normalized pipeline.
