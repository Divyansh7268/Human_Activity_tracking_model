1. EXECUTIVE SUMMARY & READINESS VERDICT
--------------------------------------------------------------------------------
Subject-Independent Evaluation Readiness: NOT READY / CANNOT BE PERFORMED

Methodological Rule:
  A subject-independent evaluation (e.g. Leave-One-Subject-Out or GroupKFold)
  requires at least 3 distinct subjects with full or representative class
  coverage. The current UP-Fall ADL dataset contains only 2 subjects, with
  severe class imbalance across subjects (Subject 2 has 0 walking samples).
  
  Performing a subject-independent evaluation under these conditions would
  violate scientific validity. In adherence to research integrity guidelines:
  - No fake folds were created.
  - No subject data was duplicated or fabricated.
  - The evaluation was halted, and readiness limitations are documented below.

4. EXACT METHODOLOGICAL LIMITATIONS
--------------------------------------------------------------------------------
1. Sample Size Limitation (N=2):
   Evaluating cross-subject generalization with N=2 provides 0 degrees of freedom
   for statistical validation. Any fold division would result in a single training
   subject and a single testing subject.

2. Complete Absence of Class in Subject 2:
   Subject 2 contains zero walking trials. If Subject 2 is held out as the test set:
   - The test set contains only standing and sitting (walking recall cannot be tested).
   If Subject 1 is held out as the test set:
   - The training set contains only Subject 2 (standing and sitting), meaning the model
     is never trained on walking and cannot predict walking.

3. External Dataset Scope:
   The published UP-Fall 3D Skeleton CSV dataset (Zenodo/GitHub) contains only fall
   scenarios (A1-A5). Activities of Daily Living (A6 walking, A7 standing, A8 sitting)
   were not pre-extracted in the public repository for all subjects. The 8 ADL files
   currently in the pipeline were created to validate the data ingestion adapter.

--------------------------------------------------------------------------------
5. RECOMMENDED NEXT DATA REQUIREMENTS
--------------------------------------------------------------------------------
To conduct a statistically valid subject-independent evaluation:

Requirement 1: Minimum of 5 to 10 Distinct Subjects
  - Each subject must perform all target activities (standing, sitting, walking, running).
  - Enables Leave-One-Subject-Out Cross-Validation (LOSO-CV) or 5-Fold GroupKFold.

Requirement 2: Full Class Balance Per Subject
  - Every subject must have at least 1-2 trials of every target class to avoid
    zero-support classes during holdout evaluation.

Requirement 3: Explicit Subject Metadata in Processed Datasets
  - Feature CSVs should retain 'subject_id' and 'sequence_id' as non-training metadata
    columns to enable automated GroupKFold(groups=df['subject_id']).

Conclusion:
  Subject-independent evaluation is deferred until a multi-subject dataset
  (>=3 subjects, all classes represented) is acquired or recorded.
